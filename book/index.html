Lapine Web Engine

What is Lapine Web Engine?

Lapine Web Engine is a curated setup and development workflow for creating websites and apps, based on some specific technical requirements and practical productivity considerations.

It is a system made for web developers to make websites and apps, partially inspired by the workflow of using a game engine to produce games.

In practice, it is a NPM module that opens in your browser on localhost, giving you a GUI for a collection of tools for building and maintaining PWAs hosted on Cloudflare.

The main feature is a drag-and-drop interface for a central sitemap object that contain settings for navigation, SEO, permissions, and dynamically loaded content.

There is also a function for packaging Custom Web Components into self-contained Kits, which can be maintained separately and distributed for use in multiple projects.

A lot of consideration has gone into isolating complexity and reducing cognitive load for developers through a standardised setup, without compromising neither granular control nor creative freedom.

While a small custom library is provided for basic functionality, Lapine Web Engine is based around pure and simple vanilla JavaScript, kept traditionally separate from both style and markup. The learning curve is very flat and friendly for anyone that quickly needs to get started from scratch.

For those who prefer AI-assisted coding, Lapine Web Engine can offer a good foundation to build upon for long-term project maintenance and support, by leveraging a clearly defined infrastructure.

Lastly, Lapine Web Engine comes with a range of basic starter recepies for common apps and websites, like a blog, a webshop, and a personal portfolio.

When maintaining several projects over time, they will eventually consist of different versions of legacy code that a developer must remember and jump between. Technical aims

Publish to all browsers and mobile devices
Modern PWAs are capable of such a wide range of functions that native development for different devices is in most cases no longer necessary. When ported through a service such as PWABuilder, it's even possible to offer traditional installation via app stores. We can therefore limit ourselves to one type of project while still be compatible with all platforms.
Have a unified pipeline for both frontend and backend
For true full-stack development we want full control over both sides of our app, from UI design to database normalisation. With Cloudflare as a backend, Lapine Web Engine is a one-stop-shop for the whole app, giving a coherent experience based on JavaScript from the bottom up.
Be developer-friendly for both humans and AI
Provide robust open-source code for commodity apps
Keep multiple projects organised and up to date
A prominent problem for freelance developers is how to properly maintain multiple projects without constantly struggling with different versions of legacy code. Lapine Web Engine offers a centralised system that cascades to all projects while keeping individual versioning and rollbacks possible.
Simplify local development for Cloudflare's platform
While Cloudflare has a great online dashboard and a very nice CLI tool for interacting with their services remotely, Lapine Web Engine offers a helpful GUI and functionality to more specifically assist with development locally.
Isolate complexity
Sitemap, kits, separation of concerns
